## Protocol Buffer & gRPC Mapper

### `protobuf-mapper`

Scans a repository for `.proto` files and protobuf/gRPC build configuration, then produces a JSON report of runtime components, libraries, and proto package mappings.

**Trigger phrases:**
- "Map protobuf definitions in this codebase"
- "Audit gRPC dependencies and proto packages"
- "Which proto packages use which gRPC libraries?"
- "Review protobuf and gRPC usage in this project"

**Example usage:**

```
Analyze this project for protobuf and gRPC usage
```

The agent will:
1. Load the output schema (from MLflow or references/output.md)
2. Locate and read all `.proto` files and protobuf/gRPC build configuration
3. Detect protoc compiler version, gRPC runtime version, and language runtime from build config
4. Extract proto packages, services, messages, and declared protobuf/gRPC dependencies
5. Emit a JSON report with no fences

**Output shape:**

```json
{
  "runtime_stack": [
    {
      "name": "protoc",
      "runtime_version": "25.1",
      "eol": false
    },
    {
      "name": "gRPC",
      "runtime_version": "1.60.0",
      "eol": false
    },
    {
      "name": "Java",
      "runtime_version": "OpenJDK 21",
      "eol": false
    }
  ],
  "libraries": [
    {
      "library_name": "grpc-java",
      "library_version": "1.60.0",
      "library_version_source": "build.gradle:15",
      "library_runtime_version": "OpenJDK 21",
      "deprecated": false,
      "opensource": true
    }
  ],
  "repo_packages": [
    {
      "package": "com.acme.orders.v1",
      "library": "grpc-java",
      "reason": "Proto package defines OrderService with gRPC service stubs generated by protobuf-maven-plugin using grpc-java runtime"
    }
  ]
}
```
